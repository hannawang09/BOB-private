# Instructions to setup data
Download few-shot images from the [Diff-II paper](https://github.com/HKUST-LongGroup/Diff-II) by running the following

`bash download_fewshot.sh`

To download Aircraft, Pet, CUB, and CUB-LT, run the following command

`python download_real.py`

To download the Car dataset, use the following link: https://www.kaggle.com/datasets/rickyyyyyyy/torchvision-stanford-cars. Move them to `real_datasets/car' after downloading.

To download the Flower-LT dataset, use the following link: https://drive.google.com/file/d/1-AU8nq9NlnoPiGZEQStGVrjfurtaWtke/view?usp=sharing. Move them to `real_datasets/flower` before extracting.
